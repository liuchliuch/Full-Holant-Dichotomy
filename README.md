# Full Holant Dichotomy

Verification code for **A Full Complexity Dichotomy for Complex-Valued Boolean
Holant Problems**, by Chenghua Liu, Boning Meng, and Juqiu Wang.

See [`certificates/README.md`](certificates/README.md) for requirements and
commands, and the [theorem-to-script map](certificates/theorem-to-script-map.md)
for the scope of each calculation.

All companion verification code was written by OpenAI Codex and subsequently
reviewed by the authors.
